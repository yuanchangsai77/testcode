# testcode v0.1

本文档是 `testcode` v0.1 的版本快照。版本文件用于记录当时已经具备的功能；后续版本不回改本文件，而是新建 `v0.2`、`v0.3` 等文件记录相对前一版本的变化。

## 定位

v0.1 是一个早期可用的本地 CLI agent runtime，已经具备模型调用、工具执行、安全审批、会话持久化和运行日志的基础闭环。

## 交互和会话

- 支持单轮命令运行。
- 支持交互式多轮对话。
- 支持 session 保存。
- 支持查看 session 列表。
- 支持按 session id 恢复会话。
- 支持选择最近 session 恢复。
- 支持交互式选择 session 恢复。
- session 文件保存在 `.testcode/sessions/`。

## 模型接入

- 支持 stub 模型客户端。
- 支持 OpenAI-compatible chat completions 模型客户端。
- 支持通过 `.env` 配置模型代理地址、模型名、超时时间和运行模式。
- 支持原生 `message.tool_calls` 解析。
- 支持 JSON content 格式的 action fallback。
- 支持将模型请求、响应和解析结果写入 run 日志。

## 工具系统

- 支持统一工具 registry。
- 工具定义包含 `input_schema`。
- 工具定义包含 `risk_level`。
- registry 执行前会校验未知工具、缺失参数和未知参数。
- 默认暴露以下内置工具：
  - `list_dir`
  - `read_file`
  - `file_info`
  - `find_files`
  - `search_text`
  - `shell_exec`
  - `run_tests`
  - `git_status`
  - `git_diff`
  - `git_show`
  - `patch`

## 文件和搜索

- 支持列出 workspace 内目录。
- 支持读取 workspace 内 UTF-8 文本文件。
- 支持查看文件类型、大小和 mtime。
- 支持按 glob 查找文件。
- 支持使用 ripgrep 搜索文本。
- 文件和搜索工具默认限制在当前 workspace 内。
- 支持结果数量和读取大小限制。

## 修改能力

- 支持通过 unified diff patch 修改 workspace 内文件。
- patch 工具会校验目标路径是否在 workspace 内。
- patch 工具会校验上下文是否匹配。
- patch 失败时返回稳定错误码。

## 命令和测试

- 支持执行 workspace 内 shell 命令。
- shell 执行返回 stdout、stderr、exit code。
- 支持执行测试命令。
- 支持测试命令超时控制。

## Git

- 支持查看当前 git 分支和工作区状态。
- 支持查看 working tree diff。
- 支持 `git show` 查看 revision。
- 支持通过受控 `shell_exec` 执行提交和推送等 Git 命令。

## 安全和审批

- 支持 `readonly`、`confirm`、`auto` 三种运行模式。
- read 工具可直接运行。
- write、execute、test、destructive 等风险动作会按策略确认或拒绝。
- 支持明显危险 shell 命令识别。
- `shell_exec` 等 execute 动作在 confirm 模式下需要用户批准。
- policy 判断独立于模型输出。

## 可观测性

- 每次 run 写入 `.testcode/runs/<timestamp>/`。
- 支持 `events.jsonl` 事件日志。
- 支持 `details.log` 详情日志。
- 日志记录 run start、model request、model response、parsed reply、tool execute、tool result、safety check、approval 和 run finish。

## 测试

- pytest 覆盖核心 engine、model client、policy、presenter 和 tools。
- 当前测试命令：

```bash
PYTHONPATH=src .venv/bin/python -m pytest -q
```
